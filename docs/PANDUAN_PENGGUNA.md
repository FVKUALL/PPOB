# Panduan Pengguna

## Cara Daftar

1. Klik **Daftar** di pojok kanan atas
2. Pilih salah satu:
   - **Google** → klik tombol Google (login/register otomatis)
   - **Manual** → isi Email, Nama Pengguna, (opsional) data rekening
3. Centang **Syarat & Ketentuan**
4. Klik **Daftar**

Data rekening digunakan jika terjadi pengembalian dana.

---

## Cara Masuk

1. Klik **Masuk**
2. Pilihan:
   - **Google** — satu klik
   - **Email / Username** — ketik lalu Masuk
   - **Akun Demo** — klik kotak biru “demo / demo@ppob.local” untuk masuk langsung tanpa daftar

---

## Cara Beli Produk

1. Pastikan sudah masuk
2. Di bagian **Produk**, pilih tab Prabayar / Pascabayar / Semua
3. Klik **Beli Sekarang** pada produk
4. Isi **Nomor Tujuan** (no. HP / ID pelanggan)
5. Pilih metode pembayaran (QRIS, VA BCA/BRI/Mandiri, E-Wallet)
6. Centang **Agreement Pembelian**
7. Klik **Proses Pembelian**
8. Tunggu hasil:
   - **Berhasil** → muncul SN/Token (jika ada) + tombol **Cetak Struk**
   - **Gagal** → sistem akan menandai pengembalian dana ke rekening Anda

---

## Cetak Struk

- Langsung setelah transaksi: tombol **Cetak Struk**
- Atau buka **Riwayat** (setelah login) → pilih transaksi → Cetak Struk
- Struk terbuka di tab baru → klik **Cetak Struk** / Ctrl+P

---

## Riwayat Transaksi

1. Login
2. Klik tombol **Riwayat** di header
3. Lihat daftar transaksi + status + SN
4. Cetak ulang struk kapan saja

---

## FAQ

Scroll ke bagian **Pertanyaan Umum (FAQ)** di halaman utama.  
Isi FAQ dikelola admin dan dapat berubah sewaktu-waktu.

---

## Keamanan

- Jangan bagikan akun Google Anda
- Pastikan nomor tujuan benar sebelum bayar (kesalahan input biasanya tidak dapat di-refund)
- Simpan struk sebagai bukti transaksi
